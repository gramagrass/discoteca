"Guardar en el sitio" escribe config.js directo en tu repo de GitHub vía su API (el sitio se actualiza solo en ~1 min). Necesitás un token fino (Settings → Developer settings → Fine-grained tokens) limitado a ese repo, con permiso Contents: Read and write. El token viaja solo a api.github.com; si no marcás "recordar", no se guarda en ningún lado. También podés descargar el archivo y subirlo a mano.
